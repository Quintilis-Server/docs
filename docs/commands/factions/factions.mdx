# Factions

O comando `/clan` é usado para mexer com os sistemas do **factions**.
Ele tem 12 subcomandos

## Comandos globais
Esses são comandos que todos podem usar.
### Create

O comando `/clan create [name] [tag]` é usado para criar um clã,
sendo quem mandou o líder do clã criado.

Ele aceita 2 argumentos o `name` e o `tag`, sendo o `tag` opcional.

### List

`/clan list [página]` lista todos os clãs.

Tem dois tipos de saídas do comando

- `/clan list`: abre uma GUI com todos os clãs.
- `/clan list [página]`: retorna no chat.

### Quit

`/clan quit` é para sair do clã que é membro.
Só pode executar esse comando, tem que ta em um clã.

### Chat
`/clan chat` alterna entre o chat global e chat do clã.

Também pode usar o prefixo `@` em uma mensagem para mandar mais rápido somente para o clã.

Ex: `@sua mensagem`

## Comandos de líder

São comandos que somente o líder do clã pode executar.

### Delete

O comando `/clan delete` é usando para deletar um clã.

### Surrender

`/clan surrender` quando em [guerra](../systems/war.mdx#Guerra), quando esse comando for executado, o clã ira se [render](../systems/war#Rendição) da guerra.

### Betray

`/clan betray` é um comando de confirmação de traição da aliança.
Quando dois clãs estão em aliança e uma guerra está para acontecer ele pede esse comando para confirmar.
