# Comandos de membros

Esse comando tem 4 subcomandos. So pode ser executado pelo líder do clã.

## Invite
`/clan member invite [nome do jogador]` convida o jogador para o clã.

## Remove

`/clan member remove [nome do membro]` remove o membro do clã.

## Promote

`/clan member promote [nome do membro]` promove o jogador a líder do clã.

Uma vez executado a pessoa que enviou o comando não será mais o líder e **não** pode mais enviar os comandos de líder.

## List

`/clan member list` lista todos os membros do clã.
