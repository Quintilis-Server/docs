# Comandos de aliados

Esse comando tem 5 subcomandos

## Add

`/clan ally add [clan]` manda um convite de aliado para o clã selecionado.
Para virar aliado o outro clã tem q aceitar.

## Remove

`/clan ally remove [aliado]` remove um aliado.

## List

`/clan ally list` lista todos os aliados do clã.

## Accept

`/clan ally accept [nome do clã]` ou `/clan ally accept [tag]` aceitam o convite enviado por outro clã.

## Reject

`/clan ally reject [nome do clã]` ou `/clan ally accept [tag]` rejeitam convite de aliado de outro clã.
