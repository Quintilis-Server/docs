# Comandos

O Quintilis usa dois plugins próprios de **factions** e **economy**.

Pra usar eles é usando os comandos `/clan` e `/home`  no factions e `/transfer` e `/listing` para o economy.
Cada um dos comandos tem varios subcomandos que serão explicados aqui.
