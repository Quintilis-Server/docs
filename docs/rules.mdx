# Regras

Quintilis é um servidor anárquico, mas algumas regras de convivencia são reforçadas.

## Racismo
Qualquer tipo de discriminação não será tolerada no servidor e deve ser reportada a um moderador.
Resultará em **BAN**.
## Cheat
Não é aceito no servidor, simplesmente porque seria injusto com quem não quer usar.
## Anti-jogo
É permitido, mas tem que ter bom senso.
Um jogador novo não tme como se defender de alguém que já está no servidor a mais tempo.
